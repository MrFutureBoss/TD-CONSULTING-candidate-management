# TD CONSULTING - Candidate Management

TD CONSULTING test developing an application for managing candidate profiles.

## Live Demo

https://td-consulting-candidate-management.vercel.app/

## Tech Stack

- React + TypeScript
- Vite
- Supabase (Database, Authentication, Edge Functions)
- Tailwind CSS

## Features

- Login/Register
- Candidate profile management (CRUD)
- Resume upload candidates
- Analytics dashboard
